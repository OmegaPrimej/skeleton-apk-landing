# Skeleton APK Landing Page

Clean landing page for downloading the Skeleton APK (debug build).

## How to open the website

After you turn on GitHub Pages, your site will be at:

**https://omegaprimej.github.io/skeleton-apk-landing/**

## Files

- `index.html` → the landing page
- `app-debug.apk` → the Android APK
- `README.md` → this file

## Turn on the website (GitHub Pages)

1. Go to **Settings** → **Pages**
2. Source → **Deploy from a branch**
3. Branch: `main`  /  Folder: `/ (root)`
4. Click **Save**

Wait 1–2 minutes and open the link above.
